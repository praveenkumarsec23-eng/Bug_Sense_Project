# BugSense - AI Smart Bug Analyzer & Fix Advisor

BugSense is an AI-assisted software defect analysis platform designed to help developers analyze bugs, identify probable root causes, detect similar historical defects, and recommend remediation strategies.

The platform combines a multi-agent bug-analysis pipeline with a continuously growing defect knowledge base so that previously resolved defects can contribute to future debugging.

## 🤖 Multi-Agent Architecture

BugSense uses five specialized agents that work together to analyze software defects.

### 1. Triage Agent

Analyzes the submitted defect and determines information such as:

- Bug category
- Severity
- Priority
- Confidence
- Potential application impact

### 2. Log Analysis Agent

Analyzes:

- Error messages
- Logs
- Stack traces
- Failure information

The agent attempts to identify the important failure point and technical context of the defect.

### 3. Root Cause Agent

Determines probable underlying causes based on:

- Bug description
- Error information
- Stack trace
- Source information
- Historical defect knowledge

### 4. Duplicate Detection Agent

Compares a newly submitted defect with historical bugs to identify similar or previously resolved issues.

### 5. Remediation Agent

Produces recommended remediation guidance using:

- Root-cause information
- Bug characteristics
- Historical resolutions
- Available defect knowledge

## 🧠 RAG & Knowledge Base

BugSense maintains a historical defect knowledge base containing resolved bugs.

Knowledge entries can contain:

- Knowledge ID
- Bug ID
- Bug title
- Programming language
- Category
- Severity
- Error information
- Root cause
- Resolution
- Source
- Resolution status

When similar bugs are analyzed in the future, historical defect knowledge can be retrieved and reused during analysis.

This creates a continuous-learning workflow where resolved defects become useful knowledge for diagnosing future software problems.

## 🖥 Application Modules

### Authentication

Provides user registration, login, authentication, and protected access to BugSense functionality.

### Dashboard

Displays information such as:

- Total bugs
- Open bugs
- Resolved bugs
- Critical bugs
- Severity distribution
- Bug categories
- Recent bug analyses
- Recent activity
- Knowledge-base statistics

### Bug Analyzer

Allows users to submit software defects for analysis.

Bug information can include:

- Bug title
- Programming language
- Description
- Error message
- Stack trace
- Source code
- Source file

The submitted information is processed through the BugSense multi-agent pipeline.

### Analysis Result

Displays structured analysis generated by the BugSense agents, including triage, failure analysis, probable root cause, similar defects, and remediation guidance.

### Bug History

Stores and retrieves previously analyzed bugs.

Historical records can contain:

- Bug ID
- Title
- Language
- Severity
- Status
- Bug type
- Priority
- Triage reasoning
- Analysis confidence

### Knowledge Base

Stores resolved defect information so historical solutions can be reused during future analysis.

### Profile

Provides user profile functionality.

### Settings

Provides application and user configuration functionality.

## 🔧 Backend Setup

Navigate to the backend directory:

```bash
cd Backend
```

### Create a Virtual Environment

```bash
python -m venv venv
```

### Activate the Virtual Environment on Windows

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Start the FastAPI Server

```bash
uvicorn main:app --reload
```

The development backend will normally run at:

```text
http://127.0.0.1:8000
```
